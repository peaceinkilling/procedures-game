# Issue Procedure — Playable Entity Roster

The final Issue build should not stop at IV2/IV4/IV5/IV6. Each item below must be assessed and either implemented or explicitly marked not independently playable.

## Demand and control documents
- Demanding document / indent
- Issue Registration Progress Sheet — Original
- Issue Registration Progress Sheet — Duplicate
- Schedule of Indents / control-number intimation
- Any applicable Issues Control Registration Sheet or equivalent control medium

## Issue Voucher characters
- IV Copy No. 1
- IV Copy No. 2
- IV Copy No. 3
- IV Copy No. 4
- IV Copy No. 5
- IV Copy No. 6

## Packing and traffic documents
- Packing Note — Original for each package
- Packing Note — Duplicate retained in book form
- Packing Completion Advice — Original
- Packing Completion Advice — Duplicate
- Road / rail / postal / local-issue transit documents as applicable
- Railway Receipt / Parcel Way Bill / convoy or collection documents where applicable
- Traffic register entry / local-issue register / postal-issue register state

## Physical and accounting entities
- Physical stores / each package
- Package No. 1 carrying IV2
- Account-card posting event
- Bin-card / stock-selection event where relevant
- Receipted acknowledgement returning from consignee
- Unit pad file bundle

## Character specification required for each entity
- Spawn point
- Complete office route
- State at entry and exit of each office
- Physical companion or document bundle travelling with it
- Documents waiting elsewhere simultaneously
- Mini-game at each control point
- Failure condition and explanation
- Final destination and closure proof
- Source paragraph/page
